# MediBuddy Medicine Search

A simple medicine search application built with React and the FDA Drug Label API.

## Features

- Search medicines by brand name
- Loading, empty and error states
- Medicine result cards
- Medicine detail page
- Responsive UI
- Request cancellation using AbortController
- Client-side query caching
- Handles missing API fields
- Detail page works after direct refresh

## Tech Stack

- React
- Vite
- React Router
- FDA Drug Label API

## Run locally

```bash
npm install
npm run dev
